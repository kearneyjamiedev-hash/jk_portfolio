High-Volume Data Processing Pipelines

Cloud-based ingestion and transformation pipelines for very large streaming, broadcast and external datasets, with strong emphasis on validation, privacy, traceability and operational reliability.

Industry ProjectGDPRAzure DatabricksPySparkData Integrity

Context

At IMRO, I worked on data processing systems ingesting large datasets from streaming, broadcast and reporting sources. The work included datasets ranging from millions to billions of records.

My Contribution

  • Built ETL pipelines using Azure Databricks, PySpark, Python, SQL and Azure Data Factory.
  • Standardised and transformed data from multiple external formats and sources.
  • Implemented validation and transformation logic to improve consistency and data quality.
  • Worked with sensitive artist and royalty data under GDPR requirements.
  • Built automation to improve repeatability, traceability and operational efficiency.

Security Relevance

Although this was data engineering rather than a dedicated security role, the work required practical data protection: privacy-aware transformations, controlled handling of sensitive data, validation, integrity checks and reliable processing of untrusted external inputs.

Confidentiality

This is proprietary industry work. Source code, internal architecture and employer data are not published. The case study focuses only on transferable engineering and security concepts.
