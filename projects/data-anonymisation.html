Personal data security project

Data Anonymisation & Ingestion Tool

A Python-based ingestion and transformation framework designed to pseudonymise sensitive fields while preserving relationships needed for downstream processing.

Personal ProjectData PrivacyPythonDeterministic Hashing

Overview

The project explores a common data-security problem: how to make operational datasets useful for processing or analysis without exposing the original sensitive identifiers unnecessarily.

Approach

  • Process structured CSV-style datasets through a repeatable ingestion workflow.
  • Apply deterministic hashing to selected sensitive fields.
  • Preserve relational consistency so repeated identifiers map consistently across transformed data.
  • Use configuration to select which fields are hashed, transformed or passed through.

Security Relevance

The project demonstrates practical thinking around pseudonymisation, data minimisation, repeatable processing, configuration-driven controls and the trade-off between privacy and downstream data usability.

What It Demonstrates

Python automation, secure data handling, deterministic transformation, data integrity and privacy-aware system design.
