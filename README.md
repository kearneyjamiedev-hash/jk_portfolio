# Jamie Kearney — Security Portfolio v3

A security-first portfolio that uses software/data engineering experience as evidence of practical
technical depth rather than presenting software engineering and cybersecurity as competing career paths.

## Pages

- `index.html` — security-first landing page
- `projects.html` — selected security-relevant work
- `experience.html` — professional experience rewritten for security hiring managers
- `cv.html` — public security-focused web CV
- `projects/digital-forensic-toolkit.html` — personal security project
- `projects/data-anonymisation.html` — personal data-security project
- `projects/grant-management.html` — proprietary industry project summary
- `projects/high-volume-data.html` — proprietary industry project summary
- `assets/styles.css`
- `assets/app.js`

## Privacy

Public contact information such as personal email and phone number is intentionally omitted.
Only professional information necessary for the portfolio is included.

## Positioning

The site is intentionally security-first:

- Security is the career direction.
- Software engineering is the professional foundation.
- Industry work is included only where it gives useful security evidence.
- Proprietary work is clearly labelled and contains no source-code promises.
