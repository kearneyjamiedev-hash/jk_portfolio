Digital Forensic Toolkit

A local forensic investigation application designed to analyse files without executing them, preserve evidence integrity and organise investigation results into a repeatable workflow.

Personal ProjectDigital ForensicsPythonFastAPIEvidence Integrity

Overview

The project started as a practical way to automate forensic file analysis and evidence logging. It has since grown into a broader investigation workspace with case management, evidence verification and security hardening as first-class design concerns.

Security Problem

A forensic tool has to treat evidence as untrusted while also preserving the integrity of the material being examined. That means analysis must be repeatable, non-destructive and explicit about what is observed versus what is inferred.

What I Built

  • Evidence ingestion and analysis workflows.
  • Cryptographic hashing before analysis to establish evidence identity.
  • Metadata extraction and normalised presentation of file information.
  • Verification checks designed to distinguish file extensions from verified file characteristics.
  • Case-oriented organisation so multiple evidence items can be grouped into an investigation.
  • Comparison and bulk-analysis workflows for repeatable examination.

Security Engineering

  • Treat uploaded files as untrusted input and avoid executing analysed files.
  • Design for size limits, malformed inputs, unsupported files and safe failure.
  • Preserve evidence integrity through pre-analysis hashing and verification checks.
  • Model threats such as path traversal, parser abuse, resource exhaustion and unsafe temporary-file handling.
  • Use audit logging and automated tests to make analysis actions reviewable and repeatable.

What It Demonstrates

This project combines software engineering and cybersecurity rather than treating them as separate skills. It demonstrates Python application development, API design, defensive input handling, forensic thinking, evidence integrity, threat modelling and testable security controls.
